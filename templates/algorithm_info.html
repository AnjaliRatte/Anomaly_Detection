Isolation Forest Tree-based / Ensemble

Isolates anomalies instead of profiling normal data points. Because anomalies are few and different, they require fewer splits to isolate, resulting in shorter path lengths.

  • Configured Parameters: contamination: 0.005, n_estimators: 100, max_samples: 0.8
  • Operational Best-Fit: High-dimensional data and rapid batch processing for sudden global spikes.

Obtained Benchmark Results (NAB Dataset)

When evaluated on Numenta Anomaly Benchmark (NAB) time-series datasets, Isolation Forest demonstrates exceptional execution speed and high precision (~0.85+) in catching sharp telemetry jumps and sudden global spikes.
